# AIHC助手插件 - 显示逻辑优化

## 🎯 优化概述

本次优化重新设计了插件的显示逻辑，提供了更加优雅和用户友好的交互体验。

## ✨ 新功能特性

### 1. 右侧边缘按钮
- **位置**：固定在浏览器右侧边缘中央
- **样式**：紧凑的垂直按钮，显示"AIHC"文字
- **交互**：悬停时展开显示"助手"，提供视觉反馈
- **优势**：不遮挡页面内容，始终可见

### 2. 侧边栏面板
- **尺寸**：400px宽度，全屏高度
- **位置**：从右侧滑入，覆盖在页面内容之上
- **内容**：完整的插件功能界面
- **动画**：平滑的滑入/滑出过渡效果

### 3. 智能切换机制
- **点击切换**：点击按钮显示/隐藏侧边栏
- **遮罩关闭**：点击遮罩层关闭面板
- **关闭按钮**：面板右上角的×按钮
- **长按选项**：长按按钮1秒显示关闭确认对话框

### 4. 响应式设计
- **桌面端**：400px宽度侧边栏
- **移动端**：全屏宽度侧边栏
- **自适应**：根据屏幕尺寸自动调整

### 5. 灵活关闭选项
- **本次访问关闭**：仅当前浏览器会话关闭
- **本页关闭**：在当前页面关闭，其他页面仍可用
- **全部关闭**：全局禁用插件功能

## 🛠️ 技术实现

### 文件结构
```
extension/src/
├── content/
│   ├── index.ts          # 主要逻辑实现
│   └── style.css         # 样式定义
├── background/
│   └── index.ts          # 后台服务
└── manifest.json         # 插件配置
```

### 核心组件
1. **切换按钮** (`#aihcx-helper-toggle`)
   - 固定在右侧边缘
   - 垂直文字显示
   - 悬停效果

2. **侧边栏面板** (`#aihcx-side-panel`)
   - 滑入动画
   - 完整功能界面
   - 响应式布局

3. **遮罩层** (`#aihcx-side-panel-mask`)
   - 半透明背景
   - 点击关闭功能

### 样式特性
- **CSS动画**：使用transform和transition实现平滑动画
- **渐变背景**：现代化的渐变色彩设计
- **阴影效果**：提供层次感和深度
- **响应式**：媒体查询适配不同屏幕尺寸

## 🚀 使用方法

### 安装插件
1. 构建插件：`npm run build`
2. 在Chrome中加载解压的扩展程序
3. 访问百舸AIHC控制台页面

### 基本操作
1. **打开面板**：点击右侧边缘的"AIHC"按钮
2. **关闭面板**：
   - 点击面板右上角的×按钮
   - 点击遮罩层
   - 再次点击切换按钮
3. **关闭插件**：长按切换按钮1秒，选择关闭选项

### 支持的页面
- 资源池列表 (`/aihc/resources`)
- 资源池详情 (`/aihc/resource/info`)
- 队列列表 (`/aihc/resource/queue`)
- 任务列表 (`/aihc/tasks`)
- 任务详情 (`/aihc/infoTaskIndex/detail`)

## 🔧 配置选项

### 存储配置
- `aihcx-helper-disabled`: 全局禁用标志
- `aihcx-helper-disabled-pages`: 禁用页面列表
- `helperConfig`: 辅助功能配置

### 样式定制
可以通过修改 `content/style.css` 文件自定义：
- 按钮颜色和大小
- 面板宽度和样式
- 动画效果
- 响应式断点

## 📱 兼容性

- **浏览器**：Chrome 88+
- **设备**：桌面端和移动端
- **分辨率**：支持各种屏幕尺寸
- **页面**：仅限百舸AIHC控制台页面

## 🐛 故障排除

### 常见问题
1. **按钮不显示**：检查是否在支持的页面，确认插件已启用
2. **面板无法打开**：检查浏览器控制台是否有错误信息
3. **样式异常**：清除浏览器缓存，重新加载页面

### 调试方法
1. 打开浏览器开发者工具
2. 查看Console标签页的错误信息
3. 检查Network标签页的资源加载情况
4. 使用Elements标签页检查DOM结构
